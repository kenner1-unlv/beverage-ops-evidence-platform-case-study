# Data Handling and Disclosure Boundary

Protecting company work data takes precedence over publishing a complete
application. This repository is a newly authored case study with its own
history. The operational source repository, raw imports, database, customer
and distributor records, correspondence, credentials, original operational
screenshots, and private operating configuration remain outside it.

The two case-study screenshots are the only approved images. They show the real
application running with invented business records and values. They were not
edited from operational screenshots. Application branding and US geography
remain; neither implies that the displayed quantities are operational results.
The screenshot files are checked byte for byte before transfer.

Worked examples in the case study are newly invented and independently
calculated. They may use different fictional values from the screenshot demo
because their purpose is to explain a rule, not reproduce a production report.
The former call duration is owner-reported; net time saving remains unmeasured.
Historical cloud release evidence is dated rather than presented as current
live verification.

Every proposed public file and material claim is reviewed for confidential
names, values, paths, URLs, embedded metadata, and unsupported implications.
The private evidence ledger and source artifacts are not part of the public
package. This review supports careful disclosure; it does not claim that old
private GitHub views were erased server-side.
